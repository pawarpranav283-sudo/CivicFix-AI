
# 🏙️ CivicFix AI - Smart Civic Issue Reporter

## 📌 About the Project
CivicFix AI is a responsive web application prototype that helps people report and track civic issues such as road damage, garbage, broken streetlights, and water supply problems.

## 🎯 Problem Statement
Citizens need a simple way to report local civic issues and monitor their status.

## 💡 Solution
CivicFix AI provides a simple interface to submit civic reports, view community reports, search and filter issues, and update their status.

## ✨ Features
- Submit civic issue reports
- Dashboard showing total, pending, and resolved reports
- Search reports by title, category, and location
- Filter reports by status
- Update issue status
- Responsive user interface
- Save reports using browser localStorage

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Submit a sample civic issue to test the application.

## ⚠️ Current Limitations
- Data is stored only in the current browser.
- Reports are not shared between different users or devices.
- No backend database or live AI API is integrated yet.
